# 🤖 CodeMentor AI

CodeMentor AI is an AI-powered coding assistant that helps developers understand programming concepts, debug code, and improve their coding skills through an interactive chat interface.

## 🚀 Features

- AI-powered coding assistance
- Ask programming-related questions
- Get explanations and solutions
- Interactive chat interface
- User-friendly frontend
- Backend API integration

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Django
- Python
- REST API

### AI Integration
- Groq API
